# SPEC — 武器改“握在手里”（体素旋转支持）

状态：已发布 4.16.1
日期：2026-11-19
版本目标：4.16.1 / versionCode 57

## 背景

4.15 的武器都立在手臂外侧（x≈±27），与手臂平行，看起来像贴在胳膊上。
本轮给体素盒子加**静态旋转**支持，武器以手掌为支点前倾/外张，并加握把遮挡，读起来是“握着”。

## 改动

- [x] `VoxelModel`：盒子支持可选 `rot`（欧拉角）与 `rot_origin`；顶点和法线一起旋转；
      `hero_parts` 拆部件时同步平移 `rot_origin`。
- [x] 全部 15 位英雄的武器改为手掌锚点（±20, 30~32, 4~7）+ 10~22° 前倾/外张；
      剑/锤/法杖/弓/盾/双匕/爪刃都加“握把遮挡”（手套色小块）或前臂贴合。
- [x] 盾牌从手臂外侧收进来（x ±23 左右）并绕 Y 轴 18~20° 转向外前方。
- [x] 披风/箭袋/斗笠/尾焰位置不变；数值与逻辑不动。

## 验收

- [x] `sim_headless` / `flow_headless` 全绿（调色板断言继续通过）。
- [x] 桌面特写 15 只 + 侧面走路：武器在手里、前倾/外张，不再平行贴臂；盾牌贴前臂；帽子/披风/箭袋不变。
- [x] 构建 4.16.1 / code 57，根目录 `TapArena-v4.16.1.apk`（27,422,096 字节，SHA-256 `DCFE908D…3BC278`），push + Release v4.16.1，资产回读哈希一致。
