# SPEC — 修复首页详情 3D 展示台「头身分离」

状态：已实现（4.33.1 / code 81）
日期：2026-11-21
版本目标：4.33.1 / versionCode 81

## 问题

4.33.0 新增的首页详情 3D 展示台（`hero_preview_stage.gd`）把英雄按装配后 AABB
归一到 94 高后近距离展示。用户反馈：**部分英雄的头和身体是分开的**，
头底和肩膀之间能直接看到背景。

## 分析

- 体素模型的 `pos.y` 是盒子**底边**（`VoxelModel._add_box` 的 y 从 0 到 size.y）。
  `_humanoid_base` 里躯干是 y26→52，头是 y56→78，**中间 52→56 有 4 单位空档**；
  脖子位置没有任何几何。
- 25 位英雄中，多数靠围巾/领口/高胸块（body 顶到 58–66）把空档盖住；
  没有领口的 4 位直接露出背景：
  - 狐狸 fox（body 顶 52）
  - 兔子 rabbit（52）
  - 青蛙 frog（52）
  - 小鹿 deer（53）
- 战斗视角是远距离俯视，空档看不出来；首页详情是近距离 3/4 展示，空档被放大后
  才暴露，所以用户只在详情页看到。
- 探针（`tests/preview_shots.gd`，临时）把 25 位英雄逐个渲染成 PNG 后按背景色扫描，
  上述 4 位在头底与肩膀之间出现整行背景穿透，其余英雄无穿透。

## 改法

- `scripts/art/block_models.gd` 的 `_humanoid_base`：在有头的分支里补一根
  **14×8×12 的脖子**（y50→58，fur 色），从躯干里伸出、接住头底（y56），
  并让脖子顶端 2 单位藏进头里，头待机左右摆动时不会露缝。
  - 已有领口/围巾的英雄（body 顶 ≥58）脖子完全被遮住，外观不变；
  - 长长 `with_head=false`，保留自己的单根细脖子，不受影响；
  - 装配后 AABB 顶端不变（头顶仍最高），身高守卫不受影响。
- `tests/flow_headless.gd` 增加**头身相连守卫**：body 部件顶端必须 ≥ 头底
  （head 枢轴抬升后），否则 `FLOW_FAIL`，防止以后再出现断头模型。
