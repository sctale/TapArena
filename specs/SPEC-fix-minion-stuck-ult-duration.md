# SPEC — 修小兵不接战 / 英雄站桩 / 大招动画太短

状态：已修复（4.26.1 / code 70）
日期：2026-11-21
版本目标：4.26.1 / versionCode 70

## 1. 小兵不攻击对面小兵

### 根因

`step_minion()` 只取「最近的一个敌人」，并且用**身体间隙 ≤ 20px** 才出手。
两波小兵生成时按 38px 列距排开，横向错开 38/76px 时永远进不了 20px 间隙，
于是从旁边擦肩而过往前进。

### 改动

- 先用 `nearest_enemy_unit()` 在 150px 内找敌方英雄/小兵：
  - 未贴身：直接朝目标靠近（不再只沿兵线走）；
  - 贴身（身体间隙 26px）：停下开打。
- 塔/水晶/巨兽走原来的 `nearest_enemy` 回退分支，身体间隙 26px 出手。
- `sim_headless` 新增 `MINION_OK`：两波同路小兵横向错开 90px，4 秒内必须互相打掉血。

## 2. 英雄卡在角落不动

### 复查

- 探针跑 3v3/5v5 多组种子：没有发现地图四角的真卡死；
  站桩主要是两类：
  1. 英雄在塔前等兵线，而小兵擦肩而过后兵线一直不推进 → 一直等；
  2. 打野在自家营地全空时站在最近营地的刷新点，最长要等 25 秒。
- 修复小兵接战后，塔前等兵的对局恢复推进（复跑探针，3v3 无站桩采样）。

### 改动

- 打野：营地全空先在最近营地等 **4 秒**，之后沿自家野区营地巡逻（`_far_own_camp`），
  不跨到敌方半场；有营地刷新立刻回去打。
- 不改塔前等兵策略：没有兵线越塔会送，等兵是正确行为。

## 3. 大招动画太短

### 根因

大招 `cast_total` 只有 0.5 秒，旋身/跳砸在 0.5 秒内放完，容易被特效和团战吞掉。

### 改动

- 大招施法动作 0.5 → **0.9 秒**（小技能仍 0.34 秒）；伤害判定仍在施法首帧，只拉长表现。
- 0.9 秒下阿狮旋风爪仍转 2.2 圈；4.26.0 恢复的所有大招专属起手特效继续保留。
- `HEROES_OK` 新增施法时长断言（小技能 0.34 / 大招 0.9）。
