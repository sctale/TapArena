# SPEC — 技能特效 2.0：对标《王者荣耀》同类技能的表现语言

状态：已实现（4.28.0 / code 73）
日期：2026-11-21
版本目标：4.28.0 / versionCode 73

用户要求：用 Design Review 逐条看 60 个技能，对标《王者荣耀》同类技能，
把特效做得更花哨、更有冲击力，适合小孩子。

> 版权边界：只借鉴「同类技能的表现语言」——预警圈、亮核、拖尾、冲击环、粒子、
> 镜头反馈；**不使用任何第三方美术、音效、图标或逐帧动作素材**。

## 1. 设计走查结论（按严重度）

| 严重度 | 问题 | 影响 |
|---|---|---|
| 🔴 高 | 小技能动作 0.34 秒、大招 0.9 秒，特效还没展开就结束 | 所有技能「看不清」 |
| 🟠 中 | 多数技能只有一层形状（几道 slash / 一圈泡泡），没有地面圈、亮核、粒子 | 画面单调 |
| 🟠 中 | 远程弹道只有一颗几何体，没有拖尾/枪口闪光 | 远程技能像纸片 |
| 🟠 中 | 命中只有一个小方块爆点，没有冲击环/火花 | 打击感弱 |
| 🟠 中 | 位移技能只有模型平移，没有残影 | 冲刺/跳跃不够帅 |
| 🟡 低 | 玩家大招没有整屏反馈 | 缺少「放大招」的仪式感 |
| 🟡 低 | 阿跳定海神针巨棍穿过身体、被光柱遮挡 | 动作看不清（4.27 已修） |

## 3. 2.0 通用层（60 条技能全部生效）

1. **起手光**：每次施法在脚下生成地面环 + 中心白闪 + 7–12 颗上窜发光火花；
   半径 ≥160 的技能再加一圈高空环和 8 颗白色火花。
2. **弹道拖尾**：每个弹道每 0.08 秒留一颗发光小点（0.16 秒淡出），远程技能不再是一根线。
3. **命中反馈**：命中爆点额外加一颗火花。
4. **位移残影**：冲刺/跳跃/闪现/后跃每 0.07 秒留一个半透明残影。
5. **玩家大招整屏轻闪**：按技能颜色 0.22 透明度闪一下，0.34 秒淡出；镜头 punch 3.4、震屏 5.5。
6. **亮度**：火花/拖尾/残影用 Additive 发光材质，核心用白色提亮；形状用技能色。
7. 小技能动作 0.5 秒、大招 1.2 秒；AI 施法期间不连放（4.27 已实现）。
