# SPEC — 首页 UI 全面优化 + 详情页 3D 英雄

状态：已实现（4.33.0 / code 80）
日期：2026-11-21
版本目标：4.33.0 / versionCode 80

## 目标

把首页从「能用的选人列表」提升到有展示感的游戏大厅，并让详情页出现可旋转的
3D 英雄，而不是一张静态头像。

## 改动

### 1. 详情页 3D 展示台（核心）

- 新增 `scripts/ui/hero_preview_stage.gd`：独立 `SubViewport` 世界，
  自带渐变背景、草地圆台、金环、暖色主光 + 冷色补光、相机。
- 复用 `BlockModels.hero_parts` / `VoxelModel.material_for`，按装配后 AABB
  归一化到 94 高，英雄站在圆台上自动旋转、上下浮动，头/手臂/尾巴轻微摆动。
- Home 用 `TextureRect` 把 SubViewport 画面贴进详情弹窗；只在详情打开时
  `UPDATE_ALWAYS`，关闭时 `UPDATE_DISABLED`，不拖累首页帧率。
- 在展示台区域按住左右拖动可手动旋转；松手后恢复自动旋转。
- 展示台外圈深色底 + 金边 + 四角金色角标；左上「3D 展示」、底部「拖动旋转 · 自动展示」。

### 2. 英雄卡片

- 选中卡增加呼吸金边与「已选」角标；卡片左侧增加定位色条。
- 名字加深色底衬；右上角增加 1–3 颗难度菱点。
- 保留两排视口与连续惯性滚动，不改变现有选人逻辑。

### 3. 首页氛围与操作栏

- 天空加暖阳光晕，云层随时间缓慢漂移，空中加入少量漂浮叶片。
- 品牌面板加金色竖条；开始按钮加呼吸光晕；模式/难度选中按钮加白色下划线。
- 底部操作栏布局与按钮热区保持不变。

### 4. 详情信息层级

- 定位/生命/攻击/射程改为带角色色左条的胶囊底衬。
- 三条技能左侧增加技能色竖条，图标/名称/冷却层级不变。
- 保留原有全部文字、按钮与安全区布局。
