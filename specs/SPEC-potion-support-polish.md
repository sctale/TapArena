# SPEC — 血瓶贴身塔后、叶灵分色、无兵不发呆

状态：已实现（4.41.0 / code 92）
日期：2026-11-22
版本目标：4.41.0 / versionCode 92

## 问题

1. **血瓶太远**：5v5 血瓶在 `path[1]`、塔在 `path[2]`，上下路相隔 900（中 636）；
   3v3 药瓶在塔后 100。玩家希望塔后距离减半。
2. **叶灵红蓝同款**：当前模型只有围巾/披风用队伍色，叶绿配色和体型完全一样，
   不像小兵那样一眼分红蓝。
3. **叶灵发呆**：探针（180 秒，5v5）复现：无己方小兵时 `front == null` 直接原地站着，
   位置停住 2.5 秒以上（例：t=145.7 lane 0 s=1485 allies=0），要等下一波走到身边。
   另有多条 `front_gap≈80` 的停住是“站兵线后 80”设计内行为，不算 bug。

## 改法

### 1. 血瓶距离减半（5v5）

- 5v5：蓝方血瓶改到 `path[1]` 与 `path[2]` 的中点，红方改到 `path[5]` 与 `path[4]` 的中点
  （上下路 900→450，中路 636→318）。
- 3v3 保持塔后 100：塔的碰撞半径 58 + 药瓶半径 30，减到 50 会把药瓶塞进塔身里；
  100 已经是贴着塔的最近可视位置。
- 回血 35%、30 秒刷新、塔毁停刷不变。

### 2. 叶灵红蓝分色（参考小兵）

- `BlockModels.support_minion(atlas, team_color, team := 0)` 增加队伍参数：
  - 蓝方：保留嫩绿叶芽 + 双叶翼 + 蓝围巾（现状）；
  - 红方：秋叶橙红配色（叶橙、叶脉深橙、光点暖金）、单尖芽 + 侧刺叶翼，围巾红，
    体型高度不变（≤56）。
- `battle_view` 传 `u.team`；`SUPPORT_OK` 分别构建两队模型，校验调色板 ≤64、高度 <60。

### 3. 无兵不发呆

- `step_support` 中 `front == null` 时不再原地站，改为沿兵线向己方基地**慢慢后撤**
  （70% 速度），直到遇到下一波兵线或回到起点；回撤时仍保持远程自卫与敌塔规避。
- 有己方小兵（`front_gap≈80`）时保持原逻辑，不改变随兵线节奏。
