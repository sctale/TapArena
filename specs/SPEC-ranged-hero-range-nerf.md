# SPEC — 远程英雄普攻射程小幅收紧

状态：已实现（4.40.0 / code 91）
日期：2026-11-22
版本目标：4.40.0 / versionCode 91（与结算页改动同版）

## 问题

玩家反馈「远程的射程有点远了，因为我们地图不大」。3v3 地图 3600×1600、5v5 3600×3600，
而远程英雄普攻射程 460–560，最长占地图边长约 15%，屏幕上一屏半外就能开火，
近战英雄很难近身。

## 改法

只改 **英雄级普攻射程**（`heroes.json` 顶层 `"range"`），按现有长短做梯度收紧：
越长的削得越多，最短的只动一点；技能射程、塔/水晶/兵线/野怪射程都不动。

| 英雄（举例） | 旧 | 新 |
| --- | --- | --- |
| 小鹿 560 | 560 | **500** |
| 猫 540 | 540 | **485** |
| 狐狸 / 白鹤 520 | 520 | **470** |
| 猫头鹰 500 | 500 | **455** |
| 长颈鹿 480 | 480 | **440** |
| 青蛙 470 | 470 | **430** |
| 兔子 460 | 460 | **420** |
| 企鹅 380 | 380 | **350** |
| 孔雀 360 | 360 | **335** |
| 绵羊 320 | 320 | **300** |
| 美西螈 / 考拉 300 | 300 | **285** |

近战（≤170）保持不变；射手最远 500，仍略长于防御塔 350。
