# SPEC — 音效近大远小（距离衰减）

状态：已发布 4.18.0
日期：2026-11-19
版本目标：4.18.0 / versionCode 59

## 背景

当前所有战斗音效都走同一个 2D 播放器池、固定 -9dB，整张地图的命中/弹道一起“啪啪啪”，很吵。
需要按音源到玩家的距离衰减：近处清楚、远处几乎听不见；UI/胜负音不受影响。

## T1 音效带位置

- [x] `BattleSim.sfx` 信号改为 `(key, pos: Vector2)`；所有 emit 补上音源位置：
      命中=受击者、弹道=发射者、爆炸=爆点、拆塔/击杀=目标点、拾取=药剂、施法/大招=施法者。
- [x] 全局事件（胜利/失败、终极对决状态切换）用 `Vector2.INF` 表示“无位置、全音量”。

## T2 距离衰减

- [x] `Sfx.play(key, volume_db, at, listener)`：`listener` 由 `main` 每帧取 `sim.render_pos(sim.player)`；
      `at` 非有限时按原音量播放。
- [x] 衰减曲线：260 单位内满音量；260→1200（大招/爆炸 1600）线性感知衰减到 -20dB；
      超过 1.2×远端直接不播（省 10 路播放器）。
- [x] `hit` 系列保留 45ms 最小间隔；BGM、点击、胜负音不变。

## 验收

- [x] `sim_headless` / `flow_headless` 全绿；桌面 `--auto-run` 200 帧无信号参数错误。
- [x] 距离探针：普通音 0→0dB、300→-0.3、600→-5.1、900→-11.9、1200→-20、1600 不播；爆炸/大招 1200→-12.4、1600→-20、2000 不播；全局音 0dB。
- [x] Android 模拟器覆盖安装，无脚本错误；远近音量曲线按探针表执行（实听由用户复核）。
- [x] 构建 4.18.0 / code 59，根目录 `TapArena-v4.18.0.apk`（27,426,192 字节，SHA-256 `82AE9A68…5AE17F1`），push + Release v4.18.0，资产回读哈希一致。
