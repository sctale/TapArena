# SPEC — 叶灵强度回调（平衡）

状态：已实现（4.39.1 / code 90）
日期：2026-11-22
版本目标：4.39.1 / versionCode 90

## 问题

4.39.0 推一路塔三路都出叶灵后，单只叶灵的数值叠成「永久光环」：

- 脉冲 2.5 秒一次、祝福持续 6 秒 → +12% 伤害 / 12% 减伤**永久覆盖**；
- 英雄回血 4% / 2.5 秒 = 96% 最大生命/分钟，小兵 8% / 2.5 秒 = 192%/分钟；
- 170 范围每 2.5 秒击退 55；640 血且会躲塔，很难被清掉。

三路同时存在后明显破坏平衡，需要回调，但保留「可爱辅助兵」的定位。

## 改法（只改数值，不改机制）

| 项目 | 旧 | 新 |
| --- | --- | --- |
| 脉冲间隔 | 2.5s | **4.0s** |
| 祝福持续 | 6.0s | **2.5s**（脉冲之间有空窗，不再永久覆盖） |
| 脉冲半径 | 230 | **200** |
| 英雄回血 | 4% | **2%**（15 次/分钟 = 30% 生命/分钟） |
| 小兵回血 | 8% | **3%** |
| 自身回血 | 3% | **2%** |
| 攻击祝福 | +12% | **+6%** |
| 减伤祝福 | 12% | **6%** |
| 击退半径 | 170 | **140** |
| 击退距离 | 55 | **30** |
| 生命 | 640 | **420**（更容易被清掉） |

- 射程、攻速、伤害（12/1.2s）、移动速度、跟兵线间距、躲避塔、死亡 60 经验都不变。
- 三路解锁、阵亡后本路下一波重出等 4.39.0 行为不变。
