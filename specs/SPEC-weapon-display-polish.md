# SPEC — 优化武器显示效果（外观高光 / 挥砍轨迹 / 待机微光）

状态：已发布 4.17.0
日期：2026-11-19
版本目标：4.17.0 / versionCode 58

## 目标

武器已经握在手里，但远看仍偏“木棍/铁片”。本轮只改表现层，让武器在固定俯视机位下更亮、更有轮廓、
挥砍更有速度感；不碰数值、AI、战斗逻辑。

## T1 武器静态外观

- [x] 剑/匕/爪刃：刃口加一条近白高光（面向外侧），刃脊加深；剑尖再提亮；剑柄加尾饰。
- [x] 法杖：法杖头（星/月牙/水泡/羽扇）中心加发光核心（glow 瓦片）；杖头略微放大。
- [x] 木锤：锤头加顶面高光与铁箍亮边，锤柄靠头处加一圈绳结。
- [x] 弓：弓臂加厚一点、弓弦更清楚，并在弦上搭一支箭（细杆 + 三片箭羽）。
- [x] 盾牌：加一圈浅色包边 + 盾心高光小块，前臂贴合处加深色绑带。
- [x] 保持握持角度与手掌锚点不变；帽子/披风/箭袋/尾焰不变。

## T2 攻击挥砍轨迹

- [x] 近战（虎/熊/熊猫/龟/刺猬/火火/狼）：在朝向前方 40~55、高度 30~45 生成 3 段弧形斩击，
      沿朝向横向铺开、带 ±20° 斜角，0.18 秒内放大淡出；颜色按武器（钢白/火橙/竹绿/尘土棕）。
- [x] 熊/龟保留尘土环 + 碎屑；命中瞬间在武器尖端再补一颗小闪光。
- [x] 弓（猫/鹿）：弓弦位置一次白色弦闪 + 现有箭线；法杖职业：杖头一次团状闪光（已有）+ 光晕小环。
- [x] 只在攻击起始帧触发一次；不改 `battle_sim`。

## T3 待机微光

- [x] 每 0.55 秒轮转一位存活英雄，在其武器尖端（身前 30、高度 40）闪一颗 0.12 秒的小星点；
      颜色按英雄武器（钢白/金/冰蓝/火橙），错开出现，不刷屏。
