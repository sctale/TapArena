# SPEC — 全员技能视觉特效优化（箭雨/冰风暴/跳砸/棍击等）

状态：已实现（4.26.0 / code 69）
日期：2026-11-21
版本目标：4.26.0 / versionCode 69

用户反馈：继续优化所有英雄的技能效果；例如「林间箭雨」应该有箭从天上射下来。

## 1. 审计结论

1. `cast()` 对 `leap / pull / multi / beam / chain` 类型**跳过** `cast_<fx>`，
   导致多段型/跳跃型大招的专属特效根本没播：
   灵灵星落、朵朵满月、泡泡瀑布、咕咕夜枭、阿岳山崩、灰灰猎影、小白风域、甲甲龟甲、
   角角箭雨——只有弹道或落点圈。
2. 角角大招 `fx = leafsmash`，没有箭；普攻/后跃虽然是箭矢弹道，但起手是叶子。
3. 新英雄多个技能复用了别人的特效：阿跳大招是虎爪、阿吨震地是通用地震、
   冰冰暴风雪是星落、云朵牧场是通用治疗圈。

## 2. 改动

### 修复大招起手

- `cast()`：`index == 2` 的 ults **无条件**播 `cast_<fx>`；`multi/leap` 也播。
- 角角「林间箭雨」特殊处理：在目标点亮 `arrow_rain`（不是脚下），
  由 `_spawn_arrow_rain` 播箭雨。

### 新特效

| 样式 | 技能 | 画面 |
|---|---|---|
| `arrow_rain_ult` / `arrow_rain` | 角角大招 | 18 支带箭头/尾羽的箭斜着从空中落下 + 7 支插地箭 + 落点小尘环 + 大范围圈 |
| `arrow` | 角角普攻/后跃 | 扇形 4 支箭射出 |
| `staff_ult` | 阿跳大招 | 金箍长棍从空中砸下 + 双层冲击环 + 尘土 |
| `staff` | 阿跳横扫 | 4 道金色棍影 + 横向亮痕 |
| `stomp_ult` | 阿吨大招 | 圆形大脚印 + 3 枚脚趾 + 双层震波 + 碎石 |
| `frost_ult` | 冰冰大招 | 16 枚冰晶旋转落下 + 地面六角雪花 + 双层冰环 |
| `frost` | 冰冰冰锥/冰面 | 6 枚冰晶散开 + 小冰环；冰锥弹道换 `ice` 晶体 |
| `pasture_ult` | 云朵大招 | 6 团云升起 + 粉色心形 + 治疗圈 |

### 已有特效修正

- 小白大招 `waterfall` → `feather`（风域羽刃，不是水泡）。
- 阿岳锥形 `leafsmash` → `quake`（山崩碎石）。
- 灰灰冲刺 `roll` → `claw`（猎影爪）。
- 甲甲嘲讽 `bubble` → `taunt`（吼声/心形）。
- 刺刺回旋 `leaf` → `spikes`（刺球）。
- 所有 20 人大招（含 multi/leap）现在都能看到原来的专属起手：星落、满月、瀑布、
  夜枭、山崩、猎影、风域、龟甲等。
