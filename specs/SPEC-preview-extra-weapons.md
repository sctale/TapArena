# SPEC — 修复详情 3D 英雄多出武器

状态：已实现（4.34.1 / code 83）
日期：2026-11-21
版本目标：4.34.1 / versionCode 83

## 问题

小用户反馈：首页详情 3D 人物「有些多了武器，应该是模型选择或者放错了」。

## 分析

- 4.15–4.17 给每位英雄加了统一的「主武器/配件」系统（`_gear_boxes` +
  `_wrap` 手掌遮挡 + 旋转握持），但**早期造型分支里手绘的旧武器没有删干净**。
- 这些旧武器在战斗远视角下和新武器重叠、看起来像加粗；首页详情 3D 展示台是近距离
  3/4 视角，两把武器错开 7 个单位并排显示，就成了「多了一把」。
- 逐英雄比对 `_hero_boxes` 与 `_gear_boxes` 后，确认重复的只有 3 位：

| 英雄 | 旧造型分支残留 | 4.15+ 统一装备 | 结论 |
| --- | --- | --- | --- |
| 老虎 tiger | 左臂三层木盾（x=-26.5，3 盒 + 绿盾心） | 左臂抛光圆盾 + 右手短剑 | 删旧盾 |
| 狐狸 fox | 右臂金杆十字星杖（x=27，3 盒） | 右手木杆金星法杖 + 紫披风 | 删旧杖 |
| 熊猫 panda | 右臂竹竿（x=27，4 盒，含竹叶） | 右手竹节法杖 + 竹斗笠 | 删旧竹竿 |

- 其余英雄没有同类重复：兔/蛙/猫/鹿/鹤/猴/象/企鹅/羊/蝠/鳄/长颈鹿/浣熊/考拉/孔雀
  的武器只在新装备里；熊是「大锤 + 小盾」、龟是「大盾」、刺猬是「双匕」、
  美西螈是「贝壳盾 + 水球」，都是设计内的双持/盾牌组合，不动。

## 改法

- `scripts/art/block_models.gd`：
  - 删除 `_hero_boxes` 里 tiger 的旧盾 3 盒、fox 的旧杖 3 盒、panda 的旧竹竿 4 盒；
  - 保留 `_gear_boxes` 中的新武器（抛光盾、金星杖、竹节杖 + 斗笠）。
- 装配后 AABB 顶端仍是头/帽，身高守卫不受影响；战斗内模型同步变干净。
