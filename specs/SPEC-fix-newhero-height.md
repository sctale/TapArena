# SPEC — 修正新英雄视觉身高并加入守卫

状态：已实现（4.30.1 / code 76）
日期：2026-11-21
版本目标：4.30.1 / versionCode 76

## 背景

4.30.0 的五位新英雄里，阿翎（孔雀）明显高于同类法师，长长（长颈鹿）的模型自然高度
132 又被 `height/88` 放大 1.19 倍，实际视觉身高达到 157，接近水晶高度。
根因：`HERO_DESIGN_H` 一律填 88，但模型自然高度并不都等于 88；
此前只检查了"有没有登记"，没有检查"登记后进游戏的真实身高"。

## 改动

1. `heroes.json`：阿翎 `height` 92 → 80（法师档，贴近灵灵 66 / 咕咕 70 / 冰冰 72 的比例）。
2. `battle_view.gd`：`HERO_DESIGN_H["giraffe"] = 132.0`，用模型自然高度抵消长脖子的额外长度；
   实际视觉身高 = 132 × (105/132) = 105，比大象略高，不再顶到水晶。
3. `flow_headless.gd`：新增按定位的视觉身高守卫，计算
   `模型装配后包围盒高度 × height / HERO_DESIGN_H`，并限制：
   坦克 72–110、战士 65–96、法师 55–90、辅助 55–108、控制 55–80、
   射手 50–82、刺客 55–82、打野/法坦 60–88；超出即 `FLOW_FAIL`。
4. `AGENTS.md`：把"新英雄必须量视觉身高、超模板要填真实自然高度、按定位守卫"
   写成长期规则，避免下次再加英雄时重犯。
