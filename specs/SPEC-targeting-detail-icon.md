# SPEC：王者式攻击选取 / 选人详情按钮 / 启动图标安全区

> 日期：2026-11-17　目标版本：4.13.0（versionCode 52）
> 范围：Godot 主线；3v3 数值与节奏不变；Web 存档不动。

## 0. 背景

用户三点反馈：

1. **普攻和技能的攻击逻辑需要优化，参照王者荣耀**：当前普攻永远打“最近敌人”，英雄不会优先；技能也一律瞄最近单位，容易对着满血小兵放大；远程普攻弹道不追踪，移动目标能侧滑躲掉。
2. **首页人物详情页的按钮需要优化**：现在只有右上角一个小「返回」和右下角一个「带它出发」，大小/位置/层级都不统一。
3. **游戏图标显示需要优化**：自适应图标前景在 432 画布里占 335×328，而圆形/圆角遮罩安全区只有 264，树木边缘会被裁掉；Android 13 主题图标也没有接入 monochrome。

## 1. 普攻选取（王者式优先级）

### 1.1 目标规则

新增 `pick_attack_target(h)`，玩家与 AI 英雄共用（嘲讽强制目标最高优先）：

| 目标 | 基础分 | 距离惩罚 | 残血加成 |
|---|---|---|---|
| 敌方英雄 | 3000 | −0.5×距离 | +600×(1−HP%) |
| 小兵 / 野怪 | 1200 | −0.8×距离 | +500×(1−HP%) |
| 防御塔 | 400 | −0.2×距离 | 无 |
| 水晶 | 200 | −0.1×距离 | 无 |

- 只在 `attack_range + 目标半径` 内选取；受保护建筑跳过。
- 当前锁定目标 `atk_target` 仍在范围内时 +280 粘性分；AI 的 `ai_target` +200，避免每次攻击抖动换目标。
- 效果：身边有敌方英雄必打英雄；没有英雄时优先补残血小兵/野怪；塔和水晶只在没有可打单位时处理。
- `atk_target` 在死亡、复活、恐惧结束时清空；新增字段只存在于 `Unit`，不参与网络/存档。

### 1.2 远程普攻追踪

- 英雄远程普攻改为 **homing 弹道**（`shoot(..., true, target, style)`）：弹道每帧朝目标当前位置修正，移动目标不能再靠侧滑躲掉普攻。
- 近战普攻维持瞬时命中；技能弹道仍为方向型（可被走位躲），保持操作空间。

### 1.3 代码落点

- `battle_sim.gd`：新增 `pick_attack_target()`、`_target_reachable()`；`step_hero()` 的普攻段改为统一调用；`Unit.atk_target` 新字段；`kill()`/`respawn()` 清空。
- 权重放 `data/rules.json` 新增 `"targeting"` 块，不在脚本写死。

## 2. 技能瞄准（王者式智能施法）

### 2.1 选目标

新增 `pick_skill_target(h, s, kind)`：

- 自身/区域类技能（aoe、radial、heal、heal_zone、shield、vanish、spin、taunt、fear、mark）不选目标。
- 方向/单体类技能（projectile、splash、boomerang、beam、cone、chain、trap、multi、pull、leap、backstep）：
  1. 优先射程内敌方英雄：分数 = 800 − 0.4×距离 + 500×(1−HP%) + 当前普攻目标 +300；
  2. 无英雄时选残血小兵/野怪：400 − 0.6×距离 + 300×(1−HP%)；
  3. 都没有才考虑建筑（仅限能打建筑的方向型技能）。
- 技能射程按 `max(range, 260) + 40` 计算，避免短技能瞄到射程外目标。

### 2.2 预判与群瞄

- **预判**：目标在移动时，瞄准点 = 目标位置 + 目标速度 × `clamp(距离/弹速, 0.12, 0.45) × 0.85`；弹速取技能 `speed`（默认 620），让直线技能能命中正常走位。
- **锥形/光束**：有英雄时对准英雄预判点；无英雄时枚举每个敌人方向与两两质心，按“命中英雄数×3 + 小兵数”选覆盖率最高的方向。
- **月链**：第一跳优先英雄；后续每跳在 `jump_range` 内优先未命中的英雄，其次残血单位。
- **星落/陷阱/回旋镖**：中心/方向优先英雄，陷阱保留原有移动预判。
- **拉/跳/后跃**：优先射程内血量比例最低的敌方英雄，而不是最近的。
- 玩家冲刺/瞬移仍按摇杆方向，不自动扭头（逃跑不被拽回）。

### 2.3 验收

- 英雄 + 小兵同时在射程内：普攻与技能都打英雄。
- 两个残血小兵：先打血量比例更低的。
- 锁定目标不因同分目标抖动；目标死亡/离开范围后自动切下一个。
- 移动英雄：直线技能落点在移动方向前方（>15px）；远程普攻追踪最终命中。
- 3v3 十局回归、建筑保护、AI 不越塔断言全部保持通过。

## 3. 选人详情页按钮

### 3.1 新布局（相对详情面板 `d`）

- 删除右上角小「返回」，底部统一操作条：
  - 「返回列表」：`x=d.x+0.035d.w, y=d.end.y−0.135d.h, w=0.26d.w, h=0.10d.h`，深绿底 + 浅描边。
  - 「带它出发」：`x=d.end.x−0.035d.w−0.36d.w`，同高，金色主按钮 + 白色高光 + ▶。
  - 中间显示「轻松 · 5v5」/「挑战 · 3v3」小字，明确当前模式和难度。
- 技能三条上移压缩：起始 0.40d.h、步长 0.135d.h、行高 0.115d.h；底部提示行 0.775d.h；按钮区 0.815–0.915d.h，互不重叠。
- 点击按钮外区域仍关闭；`detail_close_rect()` 改为返回新「返回列表」矩形，输入逻辑与 `flow_headless` 不变。

### 3.2 验收

- 两枚按钮高度 0.115d（1080p 下约 84px，大于 44vp），文字完整、不叠技能行。
- 点「返回列表」回首页网格；点「带它出发」按当前英雄/难度/模式开战。
- 桌面与 Android 实机截图矩形核对。

## 4. 启动图标显示

### 4.1 问题

- 自适应前景 432×432 中有效像素 335×328，圆形遮罩直径约 288（安全区 264），树冠/耳朵被裁。
- Android 13 主题图标需要 `<monochrome>`，当前 APK 的 `mipmap-anydpi-v26/icon.xml` 只有 foreground/background。
- 传统 512 启动图与自适应前景构图不一致。

### 4.2 改法

- 重生成 `assets/icons/app_icon_foreground.png`：保持原画，整体缩放 0.78 后居中，占用 ≤264px，四周透明。
- 新增 `assets/icons/app_icon_monochrome.png`：由前景 alpha 生成白色单色剪影（阈值化），同样缩放到安全区。
- 重生成 `assets/icons/app_icon.png`（512）：背景放大到 512 + 缩放后的前景居中合成，保证 Android 7.x 传统图标与自适应版构图一致、边缘留白。
- `tools/godot-build.ps1` 的导出预设新增 `launcher_icons/monochrome_432x432="res://assets/icons/app_icon_monochrome.png"`；背景保持现有浅青蓝天空图。
- 不改画风、不引入第三方素材。

### 4.3 验收

- 构建后 APK 内 `res/mipmap-xxxhdpi-v4/icon_foreground.webp` 有效像素 bbox ≤288（圆形遮罩内），且水平/垂直居中偏差 ≤6px。
- `res/mipmap-anydpi-v26/icon.xml` 含 `monochrome` 节点，`icon_monochrome.webp` 存在。
- 模拟器桌面截图：图标完整显示，树冠/底座不被裁切；传统图标与自适应版主体位置一致。

## 5. 验证计划

1. `sim_headless`：新增目标优先级、残血补刀、粘性、技能瞄英雄、预判、普攻追踪断言；原有 `SIM_OK/RULE_OK/SIG_OK/MAP_OK/JGL_OK/FIX_OK/LEVEL_OK` 全绿。
2. `flow_headless`：详情页新按钮路径仍 `FLOW_OK`。
3. 5v5 挑战 10 局平衡探针：记录平均时长/超时/蓝方胜场，确认目标改动没有把节奏打崩。
4. `--write-movie` 逐帧：详情页、普攻追踪（移动靶）、技能预判方向；PIL 检查按钮矩形/文字墨迹。
5. Android 模拟器：安装 4.13.0，实拍详情页与桌面图标；核对图标不被遮罩裁边。
6. 构建 + aapt2/apksigner 校验 + Release 资产回读。

- 不引入头像锁定轮盘/手动瞄准摇杆（本作面向孩子，保持自动施法）。
