# SPEC — 长长脖子改成一根到底

状态：已实现（4.32.1 / code 79）
日期：2026-11-21
版本目标：4.32.1 / versionCode 79

## 问题

4.32.0 的长长由「22 宽胸颈块 + 14 宽上颈 + 24 宽头」三段组成。
胸颈块又宽又高、正面还有奶油色块，看起来像**第二个没有眼睛的头**；
用户希望去掉中间这一段，让上面那根细脖子直接从围巾连到脑袋。

## 改法

- `_humanoid_base` 增加 `with_head` 开关；长长跳过公共人形头部（含眼/嘴/腮红），
  不再需要一块宽盒子去遮住旧脸。
- 长长新结构：
  - 一根 **14×38×14 的细脖子**，从围巾上沿（y52）直接连到 y90；
  - 24×22×22 的大圆头、大耳、小角、奶油口鼻全部保留；
  - 脖子正面一条奶油喉纹、两侧斑点、背面鬃毛；
  - 围巾、肚皮、尾巴、武器不变。
- 模型自然高度仍为 118，`HERO_DESIGN_H` 保持 118，视觉身高 105。
