# SPEC — 复活时间随死亡次数增长

状态：已实现（4.27.1 / code 72）
日期：2026-11-21
版本目标：4.27.1 / versionCode 72

用户反馈：每次死亡的复活时间需要增加 1 秒，否则英雄一直复活，没办法推塔。

## 现状

- `kill()` 里英雄复活时间固定为 `respawn_time(5.5s)`，仅按落后方塔数最多缩短 1.65 秒；
- 中后期英雄 5–6 秒就复活，推塔窗口很短。

## 改动

- `rules.json → comeback` 新增：
  - `respawn_growth: 1.0`（每次死亡 +1 秒）
  - `respawn_max: 30.0`（上限，避免无限拉长）
- `kill()`：
  `respawn_t = clamp(respawn_time + deaths * growth - 落后塔数 * 0.55, min_respawn, respawn_max)`
  - 第一次死亡 6.5 秒，第二次 7.5 秒，以此类推；
  - 落后方仍按塔数最多缩短 1.65 秒（保留原有的追赶机制）；
  - 上限 30 秒。
- 打野/巨兽/药剂复活时间不变。
