# SPEC — 叶灵改为随兵线出现 + 远程 + 击退

状态：已实现（4.38.0 / code 87）
日期：2026-11-22
版本目标：4.38.0 / versionCode 87

## 问题

4.37.0 的叶灵在推塔瞬间原地出现、近战自卫、脉冲只有回血/祝福，玩家反馈：

1. 叶灵应该随**下一波兵线**出现，死亡后随下一波新兵线再出现；
2. 叶灵要躲在普通兵线后面，攻击改为**远程**；
3. 叶灵释放技能（回血脉冲）时，自身周围带**瞬间击退**。

## 改法

### 1. 随下一波兵线出现 / 死亡后下一波再出

- 推塔时不再原地生成叶灵，而是给「队伍 × 路」记一个 `support_pending`：
  - 播报「蓝方推掉上路塔！下一波兵线叶灵来帮忙」；
  - 下一波该路兵线从基地出发时，叶灵随兵线一起出现（在兵线后方）。
- 叶灵被击败后把同一「队伍 × 路」重新标记 pending，**下一波新兵线**再出一只；
  只要该路推过塔，叶灵就会一直随兵线轮换（每波最多一只、同一路不叠）。
- 同一路已有存活叶灵时再推塔：不排新队列，只把现有叶灵补满血。
- 缓存于 `BattleSim.support_unlocked / support_pending`，`spawn_wave_lane` 末尾消费。

### 2. 躲在兵线后面 + 远程攻击

- 攻击距离 110 → **260**，用 `shoot(..., style="leaf")` 发叶绿弹道（有拖尾），
  不再贴脸；攻击间隔 1.2s、伤害 12 不变。
- 移动目标：找同路**最前面的己方普通小兵**，站在它后方约 80 弧长；
  落后就追、超前就退；没有己方小兵时原地跟队/等待，不单独冲塔。
- 敌人进入 130 内先后退；攻击在 260 内持续进行，不需要停下来。

### 3. 技能瞬间击退

- 回血脉冲（每 2.5s）释放时：
  - 保留原有回血与 6 秒 +12% 伤害 / 12% 减伤；
  - 以叶灵为中心 **170 范围**内敌方英雄/小兵/野怪**瞬间击退 55**（不击退塔/水晶/巨兽）；
  - 金色击退环 + 金色光点，叶灵本体有一次 0.3s 鼓起施法缩放；
  - 击退用现有 `move_to`，不穿水晶底座。
- 数值：`minion.support_knock_radius=170`、`support_knock_distance=55`。

### 4. 保持不变

- 外形 56 高、大圆头/叶芽帽/叶翼/发光杖/小挎包/队伍色围巾；
- 每路最多一只、可被击杀（60 经验）、小地图叶绿点 + 细血条；
- 治疗 4%/8%/3%、攻防祝福 12%、AI 回防与巨兽/九级规则不变。
