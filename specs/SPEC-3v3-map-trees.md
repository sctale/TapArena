# SPEC — 3v3 地图加宽 + 树木降高

状态：已实现（4.31.0 / code 77）
日期：2026-11-21
版本目标：4.31.0 / versionCode 77

## 问题

- 3v3 地图 3000×1600，双方外塔相距仅 720，中路一交火就贴脸，缺少拉扯空间。
- 3v3 的树沿用 5v5 的 0.85–1.35 倍缩放，最高接近 200 单位，俯视角下经常挡住英雄和兵线。

## 改动

### 1. 3v3 地图 3000×1600 → 3600×1600

- 河道/兵线仍为一条横线（y=800），蓝方基地 x=230、红方基地 x=3370。
- 兵线 7 个折点更新为：300 → 800 → 1250 → 1800 → 2350 → 2800 → 3300。
- 防御塔位置移入 `rules.json`，不再写死在脚本里：
  - 蓝方内塔 800、外塔 1250；红方外塔 2350、内塔 2800。
  - 双方外塔间距 **720 → 1100**。
- 回血药剂在外塔后侧：蓝 1150、红 2450。
- 基地坐标由 `map_w/map_h` 推导，基地/塔/药剂/兵线全部跟着地图放大。
- 3v3 小地图、地面、树石散布沿用 `sim.map_w/map_h`，自动适配。

### 2. 3v3 树木降高

- 树模型不变，只在 3v3 把实例缩放从 0.85–1.35 降到 **0.50–0.72**；
  5v5 保持原尺寸。
- 树的数量与离兵线间距不变（地图变大后密度自然下降）。

### 3. 守卫

- `sim_headless` 新增 `MAP3_OK`：3v3 地图 3600×1600、7 个兵线点、双方外塔间距 ≥1000、
  塔与药剂都在兵线上。
- `flow_headless` 在 3v3 场景检查 `scatter_tree_*` 的最大实例缩放 ≤0.85，防止树又长回去。
