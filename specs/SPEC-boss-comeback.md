# SPEC — 巨兽翻盘机制（逆风守护兽 + 终结赏金）

> 4.36.0 起改为「随机选边 + 45 秒增益 + 60 秒复活 + 5v5 九级」，见 `SPEC-boss-random-buff.md`。

状态：已实现（4.34.0 / code 82）
日期：2026-11-21
版本目标：4.34.0 / versionCode 82

## 问题

小用户反馈：**BOSS 出来后完全没有反败为胜的机会**。

现状（4.33.1）：

- 3:00（3v3）/ 4:00（5v5）按水晶血量、塔血、比分选出**优势方**，巨兽直接加入优势方；
- 巨兽 3200 血 / 130 攻 / 1.6 倍建筑伤害，带三套技能，沿兵线推塔；
- 被击败后 25 秒在优势方基地复活，还升级成飞行形态；
- 击杀巨兽的**击杀方**再获得 15 秒 +15% 伤害。

落后方原本就少塔、少血、少人头，还要同时守「优势方英雄 + 巨兽 + 兵线」；
唯一追赶手段只有按塔数缩短复活时间（最多 1.65 秒），几乎无法翻盘。

## 参考与取舍

王者荣耀/成熟 MOBA 的翻盘主要靠：**中立资源争夺**（暴君/主宰/风暴龙王）、
**终结赏金**（击杀连杀/领先方英雄拿高额奖励）、**追赶经验/经济**、
**劣势方基地保护**。本作没有金币和商店，且巨兽推塔是核心演出，完全改成中立
站桩会丢掉「巨兽帮推塔」的乐趣。因此采用「逆风守护兽」方案：

## 改动

### 1. 巨兽只帮落后方（核心）

- 巨兽出场时判定**落后方**（塔血 → 水晶血量 → 比分；完全打平时站蓝方/玩家侧），
  整局**锁定**在这一方：被击败后 25 秒回到同一方，反超也不换边。
- 不中途转投：探针里曾经试过「每次复活重新判定」，结果落后方刚用巨兽拆掉对面两座塔，
  下一次复活巨兽就转投对面，把刚打出的翻盘又夺走——体验像「背叛」，弃用。
- 击杀巨兽不会永久夺走它：击杀方获得 15 秒 +15% 伤害（原有）+ 25 秒喘口气，
  巨兽随后回到原来那一方继续推。
- 播报：出场「峡谷巨兽出现！它来帮落后的一方（蓝方）」；
  3v3 终极对决同帧合并为「终极对决！巨兽加入落后的一方（蓝方）」。
- 巨兽外观按所属阵营换色，HUD 血条颜色跟随（阵营不会中途变化）。

### 2. 终结赏金（王者式 shutdown）

- 击杀**领先方**英雄时，击杀者获得 +50% 英雄击杀经验（`comeback.shutdown_bonus`），
  头顶浮字「终结赏金！」。
- 3v3 能更快解锁二级大招，5v5 能更快追等级；被击杀的领先方英雄不额外损失经验。
- 助攻不享受该加成（保持简单、可读）。

### 3. AI 回防巨兽

- 敌方巨兽靠近己方前塔/水晶（`ai.boss_defend_dist` 520）时，AI 英雄把它作为
  高权重目标（`ai.boss_defend_weight`），主动回防，不再无视巨兽闷头推线。
- 双方 AI 通用；玩家侧由玩家自己判断，顶部巨兽血条与播报提供信息。

### 4. 数值与配置

- 巨兽基础数值、技能、25 秒复活、飞行第二形态**不变**（先只改阵营与奖励）。
- 新配置：`comeback.shutdown_bonus=0.5`、`ai.boss_defend_weight=900`、
  `ai.boss_defend_dist=520`；落后判定与 `leading_team` 共用一套比较器。
- 平衡探针（临时 `tests/boss_probe.gd`）：固定种子，巨兽出场前把一方压成落后
  （水晶 72%），分别跑 3v3/5v5，统计落后方胜率与巨兽归属；改动前后对比。
