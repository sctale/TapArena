# SPEC — 技能动作与动画清晰度再优化（定海神针/横扫逐条检查）

状态：已实现（4.27.0 / code 71）
日期：2026-11-21
版本目标：4.27.0 / versionCode 71

用户反馈：定海神针、横扫之类的技能还是看不清，要有动作和动画，画面太单调；
要求逐条检查每个技能。

## 1. 检查结论

- 小技能施法动作只有 0.34 秒，很多特效还没看清就结束；
- `cast()` 对 `leap / pull / multi / beam / chain` 跳过起手特效，部分技能只剩弹道；
- 阿跳横扫只有 4 道短棍影，没有「长棍扫一圈」的轨迹；
- 定海神针的巨型棍特效贴在英雄身上，且额外加了不透明的光柱，角色被盖住；
- 红熊猫大招用地震碎石，不像火焰冲锋；阿岳的拉/护盾起手是爱心，不贴语义。

## 2. 改动

### 时长与节奏

- 小技能施法动作 0.34 → **0.5 秒**；大招 0.9 → **1.2 秒**。伤害仍在施法首帧判定。
- AI 在 `cast_anim > 0` 时不再连放技能，保证 0.5/1.2 秒的动作完整播完。
- 大招台词改按 `cast_index == 2` 触发（不再用 `cast_total > 0.4`，避免 0.5 秒小技能误播）。
- 玩家大招镜头 punch 0.9 → **3.4**，震屏 4 → 5.5，起手有轻微推近。

### 所有技能都有起手特效

- `cast()` 不再按类型跳过：leap/pull/multi/beam/chain 也播 `cast_<fx>`；
  角角大招仍是目标区箭雨的特例。

### 阿跳

- 横扫：新增 `sweep` 动作——整圈旋身、双臂展开、长棍扫一圈；
  特效增加一根 130px 的旋转金色棍影 + 金环，不再只有 4 道短 slash。
- 定海神针：跳砸高度 34 → 50；巨棍 7×150 → 9×170，落点向侧面偏移 24px，
  不再从英雄身体正中穿过；去掉遮挡角色的光柱，改为落点金色爆点 + 双层冲击环 + 碎石。

### 其他英雄

- 红熊猫「烈焰冲锋」：`quake` → `fire_ult`（火球翻滚 + 12 颗火星上窜 + 地面火环）。
- 阿岳的拉/护盾起手：`heart` → `quake`（冲击波与碎石，符合重装近战）。
