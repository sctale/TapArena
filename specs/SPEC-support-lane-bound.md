# SPEC — 叶灵只走兵线路径（不进野区）

状态：已实现（4.38.1 / code 88）
日期：2026-11-22
版本目标：4.38.1 / versionCode 88

## 问题

4.38.0 的叶灵移动有两处不是沿兵线：

1. **后撤**：敌人贴脸（130 内）时朝「远离敌人」的自由方向退，敌人从侧面/野区方向
   接近时会把叶灵一路带进野区；
2. **跟随**：追「最前小兵后方 80 弧长」的目标点时走直线，路径拐弯时会斜穿野区；
   出生点还有 `+Vector2(0,50)` 的横向偏移，一出生就不在折线上。

玩家实际看到一只叶灵跑进野区。

## 改法

### 1. 新增 `lane_distance` 与 `_lane_move_along`

- `lane_distance(lane_id, p)`：点到兵线折线的最短距离（复用 `lane_progress` 的投影算法）。
- `_lane_move_along(m, delta, speed, dt)`：
  - 取叶灵当前在折线上的弧长 `s`，目标弧长 `s + clamp(delta, ±speed*dt)`；
  - 目标点 = `point_at_progress(目标弧长)`，朝目标点移动（离路时自动收回路径）；
  - 位移上限 `speed*dt`，速度/朝向/走路动画更新与原先一致。
- 叶灵所有主动移动都走该函数，位置永远被兵线折线牵引，不可能自由走向野区。

### 2. 后撤改为沿兵线退回己方

- 敌人 130 内：不再朝「远离敌人」的方向退，而是沿兵线向己方基地方向后退
  （蓝方弧长减小、红方弧长增大），退到 0 / 全长为止。
- 回撤帧仍可发叶弹（保留原逻辑）。

### 3. 跟随改为沿兵线推进

- 目标弧长仍是「最前己方小兵弧长 − 方向×80」；
- 与当前弧长差 < 12 时停下；否则 `_lane_move_along` 按弧长推进，不抄近路。

### 4. 出生点落在折线上

- `spawn_support_entity` 默认出生点去掉 `+Vector2(0,50)`，
  直接用兵线起点（蓝 `path[0]` / 红 `path[-1]`），一出生就在路径上。
