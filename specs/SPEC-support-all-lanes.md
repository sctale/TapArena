# SPEC — 推掉任意一路塔后，三路兵线都带叶灵

状态：已实现（4.39.0 / code 89）
日期：2026-11-22
版本目标：4.39.0 / versionCode 89

## 问题排查

玩家反馈「好像不是每一路都出现叶灵」。逐帧探针（`godot/tests/support_lanes_probe.gd`，
5v5 逐路推塔 + 自然交战 300 秒）结论：

- 现行逻辑是「哪一路塔被推，只给那一路排队」，所以只推一路时另外两路本来就没有叶灵；
  另外两路要等各自的塔被推掉才会解锁——玩家在实战里很难凑齐三路；
- 三路各自生成、死亡后下一波重出、双方对称，机制本身没有丢失（探针里每条路的塔倒下后
  都能稳定带出并重生）；
- 附带发现：叶灵不躲敌塔/敌水晶射程，跟在兵线后面站进 350/360 射程里被白打，
  推塔进到敌方半场后经常整波被塔打死，看起来「这一路又没有叶灵」。

## 改法

### 1. 推塔奖励改为全队三路解锁

- 塔被拆时不再只给该路排队，而是给推塔方的**三路**都排 `support_pending`
  （3v3 只有一路，行为不变）；播报「推掉 X 路塔！下一波三路兵线叶灵来帮忙」。
- 每路仍最多一只；该路已有存活叶灵时只补满血；已排队则不重复。
- 叶灵阵亡仍只让**自己那一路**下一波重出（其余两路不受影响）。

### 2. 叶灵不再站进敌塔/敌水晶射程

- `step_support` 先检查「叶灵到敌方 TOWER/BASE 的距离 ≤ 其射程 + 自身半径 + 40」：
  命中时沿兵线向己方后退，不再贴身跟到塔下白挨打。
- 最后 45 秒防御塔停火（`final_push`）时不躲，让叶灵能参与终极对推。

### 3. 测试

- `SUPPORT_OK` 增补：
  - 5v5 推掉任意一路塔 → 三路 `support_pending` 都有；三路各下一波 → 每路各 1 只；
  - 敌塔射程内放置叶灵，连续步进 1.5 秒：它沿兵线后退 ≥40 弧长且离路 ≤30；
  - 原有排队/随兵线/死亡重出/远程/击退/回血/5v5 断言全部保留。
