# SPEC — 结算页一眼看出哪边赢了

状态：已实现（4.40.0 / code 91）
日期：2026-11-22
版本目标：4.40.0 / versionCode 91

## 问题

结算页标题是「胜利！」/「差一点点！」，只表达玩家自己输赢；两队战绩卡外观对称，
比分条只是「蓝队 3 : 2 红队」，玩家反馈看不出**哪一边赢了**。

## 改法

### 1. 标题直接写获胜方

- 标题：`★ 蓝队胜利！` / `★ 红队胜利！`，按获胜方用蓝 / 珊瑚红；
- 副标题（原结束原因行）：`你赢了 · 水晶被摧毁` / `你输了 · 水晶被摧毁`，
  玩家视角的颜色（赢金 / 输浅红）。

### 2. 获胜方战绩卡高亮

- 获胜方卡片外框改金色 2px、卡头顶条改金色；
- 队头文字：获胜方 `蓝队 · 胜利`（金色），失败方保持队色并压暗；
- 不新增图标，避免和「★ = 输出最高」混淆。
